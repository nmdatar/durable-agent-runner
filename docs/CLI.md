# CLI Reference

Run commands through the project environment:

```bash
uv run runner <command> [options]
```

Commands using persistence default to `.runner/runner.db`. Override it with
`--db PATH`; artifacts then live beneath `PATH`'s parent directory in `artifacts/`.

## `demo`

Run the original non-durable workflow entirely in memory:

```bash
uv run runner demo [--crash-after STEP]
```

`STEP` is `plan`, `collect`, `write_report`, or `publish`. An injected crash exits
with status 1. A new invocation always starts from `plan`.

## `init`

Create or migrate the database:

```bash
uv run runner init [--db PATH]
```

Other persistent commands also initialize the schema automatically.

## `start`

Enqueue the demo without executing it:

```bash
uv run runner start demo [budget options] [--db PATH]
```

Budget options are optional integer limits:

```text
--max-attempts N
--max-steps N
--max-tokens N
--max-tool-calls N
--max-cost-micros N
```

The command prints the new run UUID.

## `worker`

Claim and execute at most one step:

```bash
uv run runner worker --once [--run-id UUID] [options]
```

`--once` is currently required. Without `--run-id`, the worker claims the oldest
eligible step across all non-terminal runs.

Coordination options:

```text
--worker-id ID       Identity recorded in claims and events; generated by default
--lease-seconds N    Lease lifetime; default 30 seconds
```

Failure injection options:

```text
--crash-after-claim STEP
--crash-before-commit STEP
--crash-after-commit STEP
--crash-after-side-effect
--retryable-failure STEP
--terminal-failure STEP
```

The retryable and terminal failure options are mutually exclusive. A simulated
process crash exits with status 1. `NO_WORK` exits successfully because an empty
queue is not an execution error.

## `inspect`

Show run status, terminal reason, accumulated usage, and every step's status,
attempt count, retry time, and last error:

```bash
uv run runner inspect UUID [--db PATH]
```

## `events`

Print the durable event history in insertion order:

```bash
uv run runner events UUID [--db PATH]
```

## `artifacts`

List artifact ID, name, media type, size, checksum, and absolute file path:

```bash
uv run runner artifacts UUID [--db PATH]
```

## `cancel`

Prevent a pending or running run from claiming additional work:

```bash
uv run runner cancel UUID [--reason TEXT] [--db PATH]
```

The command prints `CANCELLED` when it changed state and `UNCHANGED` when the run
was already terminal.

## `resume`

Drain a specific run in one local process:

```bash
uv run runner resume UUID [--crash-after STEP] [--db PATH]
```

This convenience command repeatedly invokes the same lease-aware worker until the
run completes. Prefer `worker --once` when learning or testing concurrency. It does
not wait for scheduled retries or live leases; if no step is immediately claimable,
it reports an error.

## `chaos`

Create a fresh run, inject four deterministic crashes, recover it, validate final
state, and print its event timeline:

```bash
uv run runner chaos [--db PATH]
```

A successful result ends with `status=completed`, `publish_attempts=2`, and
`publications=1`.
